# 时纪流已收集个人信息清单

**更新日期：2026-09-27**

**生效日期：2026-09-27**

本清单逐项列出时纪流（Android / iOS 客户端）实际收集的个人信息，包括本应用与内嵌第三方
SDK 收集的信息。清单与《时纪流隐私政策》第二章一一对应。

## 我们不会收集的信息

通讯录、短信内容、通话记录、已安装应用列表、剪贴板内容、
身份证件号码、人脸 / 指纹等生物识别信息、银行账号与财产信息、医疗健康信息。

> 第 19 项**不在服务端保存**：小安的对话只存在于您本次打开 App 期间的内存里，
> 清空对话或退出应用即消失。第 20 项**只用于转成文字**，转写完成后音频立即丢弃，
> 我们不保存录音，也不在后台监听。
> 第 21 项：**图片只在手机本地处理**（不上传、不保存），会上传的只有 OCR 出来的**文字**，
> 用于解析成日程草稿；解析结果只作草稿，经您在确认页确认后才写入日程。

## 说明

1. **本应用未接入任何广告 SDK、统计分析 SDK、崩溃上报 SDK、社交分享 SDK 或推送 SDK**，
   因此清单中不存在此类 SDK 收集的信息。
2. 内嵌第三方 SDK 收集的信息见《与第三方共享个人信息清单》。
3. 若后续版本新增收集项，我们会在本清单、《时纪流隐私政策》中同步更新，
   并在收集前另行征得您的同意。

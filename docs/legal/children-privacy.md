# 心安待办儿童个人信息保护声明

**更新日期：2026-09-27**

**生效日期：2026-09-27**

**版本：v1.0**

本声明依据《中华人民共和国个人信息保护法》《中华人民共和国未成年人保护法》
《儿童个人信息网络保护规定》制定，是《心安待办隐私政策》的组成部分，
与《心安待办隐私政策》不一致之处，以本声明为准。

## 一、适用范围

本声明中「儿童」，是指**不满十四周岁**的未成年人。

心安待办的主要面向人群是 18 周岁以上的高校在校生与在职人员，应用商店年龄分级为 **18+**，
我们的产品设计**不以儿童为目标用户**。但如果您是儿童的监护人，并主动为儿童注册、
使用本应用（例如家长为孩子记录学习日程），则适用本声明。

**只有在取得监护人的同意后，我们才会处理儿童的个人信息。**

## 二、我们如何收集和使用儿童个人信息

我们**不会主动向儿童收集**任何个人信息，也不会针对儿童做个性化推荐或广告推送。
在监护人代为使用的情形下，我们可能处理下列信息，且用途与《心安待办隐私政策》第二章一致：

| 信息类型 | 使用目的 | 是否必需 |
| --- | --- | --- |
| 监护人手机号、短信验证码 | 注册与登录账号 | 必需 |
| 昵称、头像 | 完善账号资料 | 非必需 |
| 日程 / 待办的标题、时间、描述 | 提供日历与待办核心功能 | 功能必需 |
| 地点文字、经纬度 | 为日程记录地点 | 非必需 |
| 图片 | 头像、待办附件 | 非必需 |

我们**不会**收集儿童的身份证件号码、生物识别信息、人脸信息、财产信息、医疗健康信息、
行踪轨迹的连续记录，也**不会**要求儿童提供与功能无关的信息。

## 三、我们如何存储和保护儿童个人信息

1. 儿童个人信息与成年人个人信息采用**相同的加密与访问控制措施**（见《心安待办隐私政策》第五章），
   并存储在中华人民共和国境内。
2. 我们实行**最小授权**：只有因工作必需且经审批的员工才能接触，并全程记录访问行为。
3. 我们不会将儿童个人信息用于任何商业目的，不会对外共享、转让或公开披露，
   除非法律法规另有规定或取得监护人的单独同意。
4. 存储期限与《心安待办隐私政策》第六章一致；超出期限后我们予以删除或匿名化处理。

## 四、监护人的权利

监护人对其所监护的儿童的个人信息享有下列权利，且**不需要支付任何费用**：

1. **查阅**：查看我们收集了哪些儿童个人信息；
2. **更正**：要求更正不准确的信息；
3. **删除**：要求删除儿童个人信息；
4. **撤回同意**：随时撤回对处理儿童个人信息的同意，撤回后我们将停止处理并删除；
5. **注销**：注销为儿童创建的账号。

行使上述权利的路径：

- App 内自助：**我的 → 隐私与合规 → 账号注销**（注销会删除该账号下的全部儿童个人信息）；
- App 内反馈：**我的 → 意见反馈**；
- 电话 / 邮箱：**【待替换：请填写客服电话】** / **【待替换：请填写客服邮箱】**；
- 或直接使用本应用「我的 → 意见反馈」，并在内容里注明「儿童个人信息」。

我们将在收到监护人请求并**核验监护人身份**后 **15 个工作日**内响应。为核验身份，
我们可能要求您提供账号绑定的手机号、可证明监护关系的材料；这些材料仅用于核验，核验完成后即删除。

## 五、监护人提示

1. 请您在注册前仔细阅读《心安待办隐私政策》与本声明，确认您已理解并同意。
2. 请您妥善保管账号与密码，避免儿童在无监管情况下自行使用。
3. 本应用**不包含**交友、社区、评论、直播、打赏等面向儿童的互动或付费功能，
   也不含任何形式的广告。

## 六、若我们未能取得监护人同意

若我们在未事先取得监护人同意的情况下收集了儿童个人信息，一经发现将立即停止处理，
并在合理期限内予以删除。监护人也可以按第四章的方式联系我们。

## 七、本声明的变更

本声明如发生变更，我们会以推送、弹窗等显著方式通知监护人，并在取得同意后再按新声明处理。

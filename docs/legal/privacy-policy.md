## 二、我们如何收集和使用您的个人信息

我们只会在下列具体场景中收集、使用您的个人信息。**未在下列场景中列举的信息，我们不会收集。**

### 2.1 手机号验证码登录（账号注册与登录）

- **使用目的**：创建并识别您的个人账号，完成登录、注册与找回。
- **收集的信息**：**手机号码**、短信验证码。
- **必要性**：手机号是本应用的账号唯一标识，不提供将无法登录，也就无法使用本服务。
- **处理方式**：短信验证码由我们的短信服务商在服务端下发，验证码在 5 分钟后失效，
  同手机号 60 秒内只能发送一条。

### 2.2 昵称与头像

- **使用目的**：完善账号资料，在「我的」页面以及组织成员列表中展示您的身份。
- **收集的信息**：您填写的**昵称**、您主动拍摄或从相册选择的**头像图片**。
- **必要性**：非必要信息。不提供时我们使用系统生成的默认名称与默认头像，不影响其他功能。

### 2.3 日程与待办

- **使用目的**：提供日历、日程、待办的新增、编辑、提醒与删除等核心功能。
- **收集的信息**：您输入的**日程/待办标题、描述、时间、重复规则、提醒设置、
  优先级、分类、链接**，以及您为这些内容附加的**图片**。
- **必要性**：这是本应用的核心功能所必需的信息；不提供则无法创建日程或待办。

### 2.4 地点与地图选点

- **使用目的**：为日程记录地点、在地图上选点、搜索附近地点、把当前位置回填为日程地点。
- **收集的信息**：您输入的**地点关键字**、您选择的**地点名称与详细地址**，
  以及开启定位后产生的**粗略/精确地理位置**、**设备当前经纬度**。
- **必要性**：非必要信息。您可以不选地点、不开启定位，也可以只手工输入文字地址，
  不影响日程与待办的其他功能。
- **处理方式**：定位由系统弹窗单独征求您的授权；地点解析由高德地图服务完成，详见 §4 与 §9.1。

### 2.5 日历页检索

- **使用目的**：在您自己的日程、待办以及您已绑定的组织日程范围内按关键字查找。
- **收集的信息**：您输入的**搜索关键字**。
- **必要性**：非必要信息。不检索不影响其他功能。
- **处理方式**：检索在服务端即时完成，**我们不记录、不存储、不分析您的搜索历史**，
  也不会基于搜索历史向您推送任何内容。

### 2.6 组织账号认领与组织日程

- **使用目的**：把您认领的组织成员身份与您的个人账号绑定，向您展示下发给您的组织日程。
- **收集的信息**：您输入的**组织唯一 ID（组织编码）**、**成员唯一识别 ID（学号 / 工号）**，
  以及由此得到的**组织名称、部门名称、真实姓名、组织角色、最近登录时间**。
- **必要性**：不提供则无法使用组织日历功能；个人日历与待办不受影响。
- **处理方式**：上述信息由您所在组织的管理员导入，我们仅作为受托处理者在组织授权范围内处理。
  唯一识别 ID 通常不是秘密，因此这是一次「认领」。如被他人冒领，可联系组织管理员解绑后重新认领。

### 2.7 图片上传与图片识别（头像、待办图片、反馈图片、日程识别）

- **使用目的**：保存您主动选择的头像，以及您为待办、意见反馈添加的图片附件；
  以及把会议通知、行程单这类照片**在本机识别成日程草稿**。
- **收集的信息**：您从**相册选择**或**用相机拍摄**的**图片内容**。
- **必要性**：非必要信息，仅在您主动使用上述功能时收集。
- **处理方式**：作为**头像 / 待办图片 / 反馈图片**提交的图片会上传到我们自己的对象存储
  （`/uploads/**`），**不会发送给任何第三方**。
  而**「识别日程」用的那张图片只在您的手机本地处理**：由手机上的 OCR 完成，
  **图片本身不上传、我们也不保存它**；但 **OCR 识别出的文字会上传至我们的服务端**，
  由模型服务商**阿里云百炼（通义千问，阿里云计算有限公司）**解析成日程草稿
  （见 §4.1 与《与第三方共享个人信息清单》）。识别结果只作**草稿**，
  经您在确认页确认后才会作为日程写入您的账号。

### 2.8 意见反馈

- **使用目的**：受理您的故障反馈与产品建议、与您取得联系并回访。
- **收集的信息**：您填写的**反馈分类、反馈内容、可选图片**，以及提交时的账号与身份标识。
- **必要性**：非必要信息，仅在您主动使用该功能时收集。

### 2.9 设备与日志信息

- **使用目的**：保障账号安全（识别登录设备、限制同一身份的活跃设备数量）、
  排查故障、满足《网络安全法》要求的日志留存义务。
- **收集的信息**：**设备标识**（App 首次启动时随机生成并保存在本机安全存储中的字符串，
  不是 IMEI、不是 Android ID，卸载后即失效）、**登录日志**（登录时间、登录结果、IP 地址）、
  **接口调用日志**（接口路径、响应码、请求追踪号）。
- **必要性**：为账号安全与合规留存所必需。
- **说明**：我们**不会**读取您的通讯录、短信、通话记录、已安装应用列表，
  **不会**读取剪贴板，**不会**在后台静默自启动或关联启动其他应用。

### 2.10 智能助手「小安」与语音输入

- **使用目的**：让您用一句话查日程、找空闲时段、建日程，并支持按住说话来输入。
- **收集的信息**：您在小安对话框里**输入或说出的话**，以及为回答您而查询到的**日程文本**
  （标题、时间、地点等）。语音会先转成文字，**转写完成后音频立即丢弃，我们不保存录音**。
- **必要性**：非必要信息。不使用小安不影响日程与待办的其他功能。
- **处理方式**：上述内容会发送给我们的模型服务商**阿里云百炼（通义千问，阿里云计算有限公司）**
  用于生成回答，详见 §9.1 与《与第三方共享个人信息清单》。
  小安**不保存对话历史**：对话只存在于您本次打开 App 期间的内存中，清空对话或退出应用即消失。
- **写操作的边界**：小安**只能在您点确认之后**创建或删除**您自己的个人日程**；
  组织下发的日程对它只读，不能改、不能删、不能下发。

### 2.11 我们不会收集的信息

我们不会收集您的**身份证件号码、生物识别信息、人脸信息、银行账号与财产信息、
医疗健康信息、行踪轨迹的连续记录、宗教信仰、特定身份、不满十四周岁未成年人的个人信息**

### 2.12 征得授权同意的例外

依据《个人信息保护法》第十三条，以下情形我们可不经您同意处理个人信息：
为订立、履行您作为一方当事人的合同所必需；为履行法定职责或法定义务所必需；
为应对突发公共卫生事件或紧急情况下为保护自然人的生命健康和财产安全所必需；
为公共利益实施新闻报道、舆论监督等在合理范围内处理；依照本法规定在合理的范围内处理
您自行公开或者其他已经合法公开的个人信息；法律、行政法规规定的其他情形。

## 四、我们如何共享、转让、公开披露您的个人信息

### 4.1 共享

我们**不会向任何第三方出售**您的个人信息。仅在以下情形共享，且共享范围限于实现功能所必需：

1. **高德地图**：当您使用地图选点、地点搜索或逆地理编码时，把您输入的
   **地点关键字**或**当前经纬度**发送给高德地图服务，用于返回地点名称、地址与坐标。
2. **短信服务商（阿里云）**：当您请求短信验证码时，把您的**手机号码**与验证码内容
   交给短信服务商完成下发。
3. **您所在组织**：当您认领组织账号后，您的**真实姓名、部门、组织角色、
   工作邮箱/工号**在组织内部可见；您收到的组织日程也会显示给同一条日程的其他收件人。
   这部分数据由组织管理者控制，我们仅提供功能。
4. **阿里云百炼（通义千问）**：① 当您使用小安对话或语音输入时，把您**输入或说出的内容**
   以及为回答您而查询到的**日程文本**发送给阿里云百炼用于生成回答；语音先转成文字，
   转写完成后音频立即丢弃。② 当您使用**「图片识别日程」**时，把手机本地 OCR 出的
   **文字**（**不含图片**，图片只在手机本地处理）发送给阿里云百炼解析成日程草稿。
   我们**不会**把您的日程内容用于训练、广告或个性化推荐。
5. **法定情形**：根据法律法规、诉讼争议解决需要，或按行政、司法机关依法提出的要求，
   对外共享您的个人信息。

详细的第三方信息、使用目的、处理方式、信息类型与其隐私政策链接，见《与第三方共享个人信息清单》
（`/api/v1/legal/shared-info-with-third-parties`，App 内路径：我的 → 隐私与合规 → 与第三方共享个人信息清单）。

我们不会转让您的个人信息给任何公司、组织和个人，但以下情形除外：
在涉及合并、收购、破产清算等情形时，如涉及个人信息转让，我们会要求新的持有方继续受本政策约束，
否则我们将要求该持有方重新向您征求授权同意。

### 4.3 公开披露

我们仅会在获得您明确同意，或基于法律法规、强制性行政或司法要求的情况下，
公开披露您的个人信息。本应用**没有**任何公开的个人主页、社区、评论或分享到第三方的功能。

### 4.4 例外

以下情形共享、转让、公开披露您的个人信息无需事先征得您的授权同意：

## 五、我们如何保护您的个人信息

### 5.1 技术措施

1. **传输加密**：客户端与服务端之间使用 HTTPS / TLS 通道传输，防止数据被窃听与篡改。
2. **权限隔离**：个人身份与每个组织身份各自持有一套独立令牌，实现组织间数据隔离；
   组织管理端只能操作本组织的数据，成员只能看到下发给自己的组织日程。
3. **访问控制**：服务端所有业务接口均要求携带有效令牌；组织管理端的写操作全部记入**审计日志**
   （仅可追加、不可修改或删除）。
4. **密码与凭据**：账号密码使用 BCrypt（cost ≥ 10）单向哈希存储，我们无法还原您的明文密码；
   刷新令牌保存在服务端且可吊销；登录凭据保存在移动设备的系统安全存储中。
5. **图片存储**：上传的图片按内容哈希命名，存储于我们自己的存储介质中，不投递给第三方。
6. **最小化接口**：接口按「当前身份是否需要」返回字段，不返回与场景无关的个人信息。

### 5.2 管理措施

我们建立了数据安全管理制度与操作规程：对员工按最小必要原则授权并定期复核；
与可接触个人信息的人员签署保密协议；定期开展安全培训与应急演练。

### 5.3 安全事件处置

若不幸发生个人信息安全事件，我们将立即启动应急预案、采取补救措施，
并以推送通知、站内信、短信或电话等方式及时告知您：事件的基本情况和可能的影响、
我们已采取的处置措施、您可自主防范和降低风险的建议、对您的补救措施等。
按照法律法规要求，我们还将向监管部门报告事件处置情况。

### 5.4 安全风险提示

请您使用复杂密码并妥善保管账号信息；我们通过上述措施尽力保障安全，
但互联网环境并非绝对安全，请理解可能出现因不可抗力或第三方恶意攻击导致的风险。

## 六、信息的存储

### 6.1 存储地点

我们在**中华人民共和国境内**收集和产生的个人信息，全部存储在**中华人民共和国境内**的服务器上；
目前不存在向境外传输个人信息的情形。如未来确需跨境传输，我们将依法进行安全评估、
单独征得您的同意，并履行法律法规规定的其他义务。

### 6.2 存储期限

我们按照下列期限保留您的个人信息，超出期限后予以删除或匿名化处理：

| 信息类型 | 保存期限 |
| --- | --- |
| 账号信息（手机号、昵称、头像） | 自账号注册之日起，至您注销账号为止 |
| 日程、待办、提醒、图片 | 自创建之日起，至您删除该内容或注销账号为止 |
| 组织成员关系与组织日程 | 由您所在组织的管理员管理，至组织管理员移除或组织解散为止 |
| 意见反馈 | 自提交之日起 2 年（用于回访与产品改进） |
| 登录日志与接口调用日志 | 自产生之日起不少于 6 个月（履行《网络安全法》第二十一条日志留存义务） |
| 安全审计日志 | 自产生之日起 3 年 |
| 小安的对话内容 | **不在服务端保存**：只存在于您本次打开 App 期间的内存中，清空对话或退出应用即消失 |
| 语音输入 | **不保存音频**：录音只在内存中传给模型服务商用于转成文字，转写完成后即丢弃 |

### 6.3 停止运营

您可以在日程、待办详情页编辑或删除内容；在「我的」页面长按（或点击）头像与昵称进行修改。

### 7.3 撤回同意与权限管理

您可以在系统设置中关闭相册、定位、通知、麦克风等权限，撤回对相应个人信息收集的同意。

不开启相册仍可手工新建日程与待办，不开启通知只是到点不再提醒，

### 7.4 账号注销

**注销是您的权利，我们不设置任何不合理条件。** 注销路径如下：

> **App 内：我的 → 隐私与合规 → 账号注销 → 阅读注销须知 → 勾选「我已了解上述后果」 → 确认注销**

提交后**立即生效**，无需人工审核，**也不超过 15 个工作日**。注销后我们将：

1. 立即吊销您账号的全部登录凭据与设备会话，所有已登录设备同时退出；
2. **删除**您的个人日历、日程、待办、提醒与图片，以及您提交的意见反馈；
3. **匿名化**您的账号信息：手机号变为不可逆的注销标识、密码与第三方绑定信息被清空，
   使该条记录无法再与您本人关联；
4. 把您的组织成员身份与本账号**解除绑定**（组织侧的成员记录保留，您可以用原学号 / 工号
   重新认领，或由组织管理员另行处理）；
5. 依法**保留**登录日志等法律法规要求留存的最小记录（见 §6.2）。

注销完成后，同一手机号可以重新注册，但那将是一个全新的账号，原数据无法恢复。

如果您无法通过 App 自助完成注销，也可以通过 §1.4 的客服电话、邮箱提出，
我们将在核验身份后于 15 个工作日内完成，并同样受本条款约束。

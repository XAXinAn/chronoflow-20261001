## 为什么只有这一份

应用宝的《隐私政策提交内容及审核规范》要求「**您提交的隐私政策链接的内容必须与 APP 内的隐私政策保证完全一致**」。
如果 App 内嵌一份、服务器上再放一份，两边必然漂移。

因此本项目：

1. 只有本目录一份 Markdown；
2. 后端把同一份 Markdown 渲染成 HTML 后挂在 `/api/v1/legal/{doc}`（公开、免登录、纯静态、无脚本）；
3. **App 直接用 WebView 打开同一个地址**——App 内看到的内容与服务端链接内容天然逐字一致，
   不存在「更新了一边忘了另一边」的可能。

改了这里的文本，App 与链接**同时**生效，无需发版。
